# FolderPilot

Organize, find and clean messy files on your own computer — a local-first PWA. See `CLAUDE.md` for the product spec and `PROGRESS.md` for status.

```bash
npm install
npm run dev        # http://localhost:5173 (use Chrome or Edge)
npm run build      # typecheck + production build
npm test           # Vitest
npm run sample     # generate ./sample-messy (500+ messy test files); add -- <path> or --force
```
